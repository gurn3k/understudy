# 0004. Dataset terms: CC BY 4.0 with attribution

## Decision
Use the BPI Challenge 2019 log under its stated CC BY 4.0 licence. The page and README credit van Dongen (2019), 4TU.ResearchData, with the DOI and a link to the licence, and say that the figures are derived from the log.

## Alternatives
None needed. 4TU's General Terms of Use apply only to datasets with no other licence, and this record states CC BY 4.0 (checked through the 4TU API, 2026-11-15).

## Why
CC BY allows reuse and derived work, including commercial use, as long as attribution is given.

## Consequences
The attribution must appear on every public page. The raw log isn't re-hosted, only derived figures and case IDs.
